# network-fundamentals-lab 학습 기록

[gnu-gnu/network-fundamentals-lab](https://github.com/gnu-gnu/network-fundamentals-lab)를 교재로 삼아
네트워크 기초(TCP/IP)를 공부한 개인 학습 기록 레포다. 교재 레포는 그대로 두고(언제든 `git pull`로 깨끗하게
업데이트 받을 수 있게), 이 레포에는 학습 과정에서 나온 노트와 발표자료만 쌓는다.

## 교재가 어떤 레포인가
"개념 하나를 잡고, 그 개념이 깨졌을 때 나는 장애를 직접 재현→관찰→원인→수정→교훈 순으로 체득하는"
실습 시리즈. containerlab으로 토폴로지를 띄워 일부러 고장난 네트워크를 고치면서 배운다.
00(온램프)부터 17(동적 라우팅)까지, L2 → L3 → 오버레이 → Transport/상태 → MTU → 이름 해석 → 심화 순으로 쌓는다.

## 어떻게 공부했나
단순히 커맨드를 따라 치지 않고, 아래 5단계를 매 개념마다 반복하는 **소크라테스식**으로 진행했다:

1. 질문 던지기
2. 실습 전에 먼저 추측으로 답변
3. 실습(명령 실행)으로 직접 검증
4. 개념 설명
5. 원래 답변이 왜 맞았는지/틀렸는지 구체적 피드백

모든 설명은 전공 용어를 바로 던지지 않고 "중학교 2학년도 알아듣게" 쉬운 비유로 먼저 풀고 나서
정식 용어를 붙이는 방식으로 진행했다 (예: 비트 = 전등 스위치 on/off).

전체 방식과 세션/노트 컨벤션의 원본은 [`GUIDE.md`](GUIDE.md)에 있다.

## 구조
```
00-onramp/            # 장(챕터) 하나 = 폴더 하나, 교재 레포의 장 폴더 이름과 동일하게
├── 노트.md           # 그 장의 Q&A 기록 (①질문 ②추측 ③실습결과 ④설명 ⑤피드백)
└── 슬라이드.html     # 장이 끝나면 만드는 공유용 발표자료 (있는 경우만)
01-l2-arp/
├── 노트.md
└── 슬라이드.html
```
